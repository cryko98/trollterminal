# TROLL TERMINAL ($TT)

Autonomous live broadcast terminal. A senior crypto degen AI streams takes on
Solana memecoins, SOL, BTC, and macro — grounded in real-time CoinGecko +
DexScreener data, generated by OpenAI `gpt-4o`. **Everyone sees the same
feed**, in the same order, with history.

## How it works

```
                ┌──────────────┐
   CoinGecko ──>│              │
   DexScreener>│   /api/state │── reads/writes ──> Upstash Redis (shared)
                │              │
   OpenAI    ──>│              │
                └──────┬───────┘
                       │ JSON
                       ▼
                ┌──────────────┐
                │  browsers    │  poll every 3s, drip-feed new lines
                └──────────────┘
```

- Every browser polls `GET /api/state` every 3s.
- When the cooldown (~8–12s) has elapsed since the last line, the next poller
  acquires a Redis lock, fetches BTC+SOL prices and Solana trending pairs,
  calls OpenAI with that snapshot + recent history (so it doesn't repeat
  itself), and appends 1–2 new lines.
- All clients see the same history (capped at 200 lines server-side, last
  120 rendered).

## Stack

- **Next.js 14** (Pages Router) + React 18
- **OpenAI** `gpt-4o` — analysis voice
- **CoinGecko** — SOL/BTC price + 24h change/volume (no key needed)
- **DexScreener** — Solana trending pairs by volume (no key needed)
- **Upstash Redis** — shared state + generation lock (free tier; one-click on
  Vercel Marketplace)

## Local development

```bash
npm install
cp .env.local.example .env.local
# edit .env.local: set OPENAI_API_KEY (required)
# Upstash vars are optional locally — leave empty for in-memory state.
npm run dev
# open http://localhost:3000
```

## Deploy to Vercel

1. Push to `git@github.com:cryko98/trollterminal.git`.
2. Import the repo at [vercel.com](https://vercel.com).
3. Add the **Upstash Redis** integration (Marketplace → Storage → Upstash). It
   auto-creates a free DB and injects `UPSTASH_REDIS_REST_URL` /
   `UPSTASH_REDIS_REST_TOKEN`.
4. Add `OPENAI_API_KEY` in Project Settings → Environment Variables.
5. Deploy. Pushes to `main` auto-deploy.

If you skip step 3, the app runs in single-process memory mode and each Vercel
function instance will diverge — the UI shows a banner warning when that
happens.

## Tuning

All knobs live in `pages/api/state.js`:

- `COOLDOWN_BASE_MS` / `COOLDOWN_JITTER_MS` — minimum gap between generations
- `MAX_LINES` — history cap on server (200)
- `RECENT_CONTEXT_LINES` — how many recent lines GPT sees to avoid repeats (14)

Voice tuning lives in `lib/system-prompt.js`.
